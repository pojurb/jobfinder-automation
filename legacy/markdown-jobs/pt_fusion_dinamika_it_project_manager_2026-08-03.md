LOWONGAN KERJA
IT PROJECT MANAGER
IT / System Integrator  |  Full-time  |  Mid-Level (3–5 tahun pengalaman)
TENTANG PERAN
Kami mencari IT Project Manager untuk memimpin implementasi proyek IT bagi klien enterprise, untuk solusi infrastruktur, dan cybersecurity. Anda akan menjadi penghubung utama antara tim teknis, klien, dan vendor, memastikan proyek selesai tepat waktu, sesuai anggaran, dan sesuai spesifikasi yang disepakati.
TANGGUNG JAWAB
Mengelola 2–4 proyek IT secara bersamaan, dari fase perencanaan sampai go-live, termasuk menyusun project charter, timeline, dan RAB (rencana anggaran biaya).
Memantau progres proyek menggunakan tools seperti ClickUp, Jira, atau sejenisnya.
Mengoordinasikan tim internal (engineer, admin project) dan vendor eksternal agar semua pihak bergerak sesuai jadwal.
Mengidentifikasi risiko keterlambatan atau perubahan scope sejak dini, dan mengusulkan mitigasi ke stakeholder.
Memimpin rapat progres mingguan dengan klien, menyiapkan laporan status proyek, dan menangani eskalasi masalah teknis maupun komersial.
Menyusun dokumentasi proyek (BOQ, UAT, handover document) untuk memastikan serah terima ke tim operasional berjalan lancar.
KUALIFIKASI
Minimal 3–5 tahun pengalaman sebagai Project Manager di perusahaan IT/System Integrator, dengan rekam jejak menangani proyek implementasi jaringan, infrastruktur, atau software enterprise.
Pengalaman langsung berhadapan dengan klien korporat menjadi nilai plus besar.
Memahami metodologi project management (Waterfall dan Agile/Scrum) dan terbiasa menggunakan tools seperti MS Project, Jira, Trello, atau Confluence.
Sertifikasi minimal CAPM, dan PMP lebih disukai, meski bukan syarat mutlak.
Memiliki pemahaman teknis dasar tentang infrastruktur IT (jaringan, server, cloud) untuk berdiskusi setara dengan tim engineering.
Kemampuan komunikasi dan negosiasi yang kuat, terutama untuk menjelaskan isu teknis ke stakeholder non-teknis dan menangani ekspektasi klien.
Terbiasa bekerja dengan target ketat, mampu mengelola beberapa proyek sekaligus tanpa kehilangan detail.
Kemampuan bahasa Inggris aktif (lisan dan tulisan) untuk komunikasi dengan vendor/klien internasional.
Pendidikan minimal S1 di bidang Teknik Informatika, Sistem Informasi, Teknik Industri, atau bidang terkait.
